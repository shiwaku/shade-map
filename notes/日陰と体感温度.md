# 日陰と体感温度 — 研究による裏付け

本アプリ（時間帯別 日陰マップ）の前提「夏の日中は日陰を選んで歩くと涼しい／熱中症リスクが下がる」は、
体感（気のせい）ではなく、多数の研究で**放射負荷の低減として定量化**されている。

## なぜ日なた/日陰で体感が違うか
- 日なたと日陰で **気温（乾球温度）はほとんど変わらない**（せいぜい数℃）。
- 体感差の主因は、直達日射による **平均放射温度 MRT（Mean Radiant Temperature）** の差。
- そのため「暑さ指数 **WBGT**」は黒球温度＝放射を含めて測り、体感系指標
  （**UTCI / PET / SET\***）も放射を重視する。
- → **日陰マップが意味を持つ理由そのもの**。

## 実証されている数値（代表例）
| 指標 | 日陰による低下量 | 備考 |
|---|---|---|
| MRT（平均放射温度） | 約 **15〜25℃** 低下 | 研究により最大16℃、最大24.8℃の報告 |
| PET（生理的等価温度） | 約 **6〜12℃** 低下 | 樹木・遮蔽装置の日陰 |
| UTCI | 約 **4〜6℃** 低下 | 「強い熱ストレス(UTCI≧32℃)」の暴露を明確に低減 |
| WBGT（日傘＝携帯する日陰） | 平均 **1.8℃**・最大 **2.9℃** 低下 | 環境省の実測 |

- 気温はほぼ同じでも、**体感指標では10℃前後変わり得る**。
- 国内でも **川崎市環境総合研究所** が街路樹の緑陰による暑熱軽減・熱中症予防効果を実測研究。

## まとめ
「日陰は涼しい」は放射負荷の低減として定量化されており、
夏の日中に日陰を選ぶだけで熱中症リスク指標（WBGT/UTCI/PET）が実質的に下がる。
本アプリで日陰の位置と時間変化を可視化する意義はここにある。
